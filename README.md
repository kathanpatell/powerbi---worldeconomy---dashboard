# 🌍 World Economy Analysis Dashboard

## Overview

This Power BI project provides a comprehensive analysis of global economic, demographic, health, development, and environmental indicators. The dashboard enables users to explore trends and compare countries across multiple dimensions using interactive visualizations and geographic mapping.

The objective of this project is to transform raw international data into actionable insights that can support economic research, policy evaluation, and strategic decision-making.

---

## Dashboard Pages

### 1. Economic Overview
Key economic indicators and country-level performance metrics.

### 2. Economic Maps
Interactive geographic visualizations showing economic trends across countries and regions.

### 3. Population Maps
Population distribution and demographic analysis through map-based visualizations.

### 4. Sex Ratio Map
Country-level comparison of population gender ratios.

### 5. Health Indicators
Analysis of health-related metrics and country comparisons.

### 6. Development Indicators
Insights into development measures and socioeconomic progress.

### 7. Environmental Indicators
Environmental performance and sustainability metrics across countries.
